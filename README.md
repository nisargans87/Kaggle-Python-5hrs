## 🔷 About This Repository

Welcome to my **Kaggle Python Learning Repository**!

This repository documents my journey through Kaggle's **5-Hour Python Course**, from understanding Python fundamentals to solving exercises and writing additional programs independently.

The goal is not just to complete the course, but to strengthen my programming fundamentals through hands-on practice, experimentation, and consistent revision.

🔗 **Kaggle Profile:** [nisargansgowda](https://www.kaggle.com/nisargansgowda)

## 🎯 Learning Objectives

- 📘 Understand Python syntax and core programming concepts.
- 🧩 Solve exercises provided throughout the course.
- 💻 Write clean, readable, and well-organized Python programs.
- 🔍 Experiment with alternative approaches to problems.
- 🚀 Implement extra programs beyond the course exercises.
- 📝 Maintain a revision-friendly collection of solutions and notes.

## 🧪 My Learning Workflow

1. **Learn** — Follow the tutorial and understand the concept.
2. **Practice** — Attempt the exercises independently.
3. **Implement** — Write and test the Python solution.
